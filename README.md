# 云程旅行 · 航空旅行一站式服务平台

面向旅客与旅行社的一站式旅行服务课程项目，整合航班搜索、智能推荐、动态票价模拟、订单管理、模拟支付、在线值机与行程规划。

## 快速开始

运行要求为 Node.js ≥24。项目没有第三方运行依赖，使用 Node.js 内置 HTTP 服务和 SQLite。

```powershell
git clone https://github.com/lonelyhty/hebut-xiecheng-se24-gpt.git
Set-Location hebut-xiecheng-se24-gpt
npm start
```

打开 <http://127.0.0.1:4173/>。

推荐工具链为 `.nvmrc` 指定的 Node.js 24.18.0 与 `packageManager` 指定的 npm 11.16.0。Node.js 24 使用内置 SQLite 时可能显示 ExperimentalWarning。

## 功能

| 模块 | 已实现内容 |
|---|---|
| 航班搜索 | 8 个城市、56 个方向组合，每个日期生成 5 个模拟航班；日期、舱位、人数查询，航空公司和预算筛选，多种排序 |
| 智能推荐 | 根据票价、飞行时长、出发时段进行规则评分，并展示推荐理由 |
| 动态票价 | 模拟需求每 5 分钟更新，含税价格展示，报价锁定 10 分钟 |
| 预订与订单 | 1–6 位乘机人、服务端金额校验、余票原子扣减、幂等创建、状态筛选与事件时间线 |
| 模拟支付 | 成功与失败响应、模拟出票、取消及退款、15 分钟支付超时后释放库存 |
| 在线值机 | 单人已出票订单，起飞前 48 小时至 45 分钟开放；30 排 A–F 选座、座位冲突校验、模拟登机牌下载 |
| 酒店与门票 | 精选目录、目的地筛选，联动行程规划 |
| 行程规划 | 1–7 日行程、住宿与门票及餐饮交通预算、历史保存、文本下载 |
| 多角色 | 旅客与旅行社演示身份；角色订单隔离、代订工作台和统计 |
| 响应式界面 | 桌面侧边导航、移动底部导航、模态表单、加载反馈、错误提示、键盘焦点与减少动画偏好 |

## 演示流程

1. 首页默认查询“上海 → 北京，明天”，选择航班并点击“预订”。
2. 点击“填入演示信息”，创建订单。
3. 可先尝试“模拟支付失败”，再使用“模拟支付”完成出票。
4. 单人订单在开放时间内可选座值机，并保存模拟登机牌。
5. 在“我的订单”查看历史，或从酒店、门票入口规划目的地行程。
6. 右上角切换演示角色，进入旅行社工作台查看代订数据。

所有航班、价格、库存、评分、支付、票号、PNR 和登机牌均为本地模拟数据。演示身份无需密码，同一角色共享示例账户；请使用虚构乘机人信息。酒店与门票支持查询和规划，未实现独立交易。

## 技术架构

前端使用 HTML、CSS 与浏览器 ES Modules，通过 JSON API 调用后端；后端使用 Node.js HTTP 与 SQLite。开发环境由同一进程提供静态文件和 API。

```text
frontend/            页面、交互、样式与 SVG 插画
backend/catalog.mjs  城市、航班时刻、酒店与门票目录
backend/service.mjs  推荐、定价、报价、订单与行程规则
backend/store.mjs    SQLite 数据表、事务与事件记录
backend/server.mjs   HTTP API、演示会话与静态资源入口
tests/               HTTP 功能测试和 SQLite 持久化测试
scripts/             插画生成与性能测试
reports/             需求设计、API、测试与性能报告
data/                自动生成的本地数据库，已忽略
```

## 测试

```powershell
npm test
npm run test:performance
```

功能测试使用临时 SQLite 和实际本地 HTTP 请求，覆盖搜索、订单状态、报价过期、幂等、并发库存、支付、取消、座位冲突及持久化。性能测试启动独立临时服务，测量 300 次查询、10 并发下的延迟与吞吐。

## 运行配置

| 环境变量 | 默认值 | 用途 |
|---|---|---|
| `HOST` | `127.0.0.1` | 服务监听地址 |
| `PORT` | `4173` | HTTP 端口 |
| `TRAVEL_DB` | `data/travel.sqlite` | SQLite 文件路径 |

使用 Ctrl+C 停止服务，再次启动会读取已有订单。需要空白演示时，可将 `TRAVEL_DB` 指向一个新的数据库文件。

## 模拟服务与后续扩展

支付与航信使用本地模拟适配器。设计文档给出了真实网关接入时的支付意图、回调验签、幂等、异步出票与补偿方案。

当前未实现生产身份认证、真实支付与库存、多人逐人值机、酒店/门票交易、往返/国际/中转航班，以及真实路网与营业时间校验。
