记录日期：2026-10-20（Asia/Shanghai）。功能测试实际执行环境为 Windows x64、Node.js v24.14.0、npm 11.9.0。

## 功能与持久化

`npm test`：**13 项通过，0 项失败**。运行输出见 [tests.tap](tests.tap)。

HTTP 测试通过实际回环网络请求访问临时服务；持久化测试使用独立的临时 SQLite 文件，并在完成后清理。

覆盖范围：

- 航班筛选、排序、舱位与含税价格。

- 并发预订最后一张票、不同订单重复占座。
- 报价过期、订单超时与库存释放。
- 酒店、门票查询及行程预算。
- SQLite 重启后的订单、锁定金额、商务舱与库存保留。
- 静态资源访问、内容类型与内容安全策略。

时间相关测试使用固定时钟验证边界；浏览器流程使用运行时钟及默认次日出发日期。

## 搜索性能

运行 `npm run test:performance`。数据见 [performance.json](performance.json)。

| 指标 | 实测 |
|---|---|
| 场景 | 回环 HTTP，上海→北京，5 个模拟航班，20 次预热 |
| 请求数 / 并发 | 300 / 10 |
| 成功 / 失败 | 300 / 0 |
| P50 / P95 / P99 | 6.66 / 10.77 / 13.47 ms |
| 吞吐 | 1420 次/秒 |
| 验收标准 | 无失败且本地 P95 <250 ms，通过 |

测量范围为本机预热进程与内存 SQLite；不包含跨主机网络、TLS、真实外部 API、大型数据集或生产负载。搜索吞吐不等于订单写入吞吐，并发库存另由功能测试验证。

## 重现

```powershell
npm test
npm run test:performance
```

上述命令启动独立测试服务，不需要访问外部业务系统。浏览器场景可参照表格，在运行中的本地平台依次操作。
